# 记忆提取系统架构文档

## 概述

记忆提取系统是 Nexus AI Assistant 的核心组件，负责从对话中自动提取、去重、存储和检索用户相关的记忆信息。系统采用**规则 + 语义驱动**的架构，支持双模型配置（专用记忆提取模型 + 主对话模型），并具备完整的兜底策略。

**核心原则**：
> **模型可以犯错，但 Filter 不能放错。**
> 
> **宁可错杀 90%，也不能放过 1 条 hallucination。**

**文件**: `src/agent/memory/MemoryExtractionService.ts`

```typescript

}
```

**增量提取机制**:
```typescript
// 只处理新消息，避免重复提取
const newMessages = messages.slice(this.lastProcessedIndex);
const newContentLength = newMessages.reduce((sum, m) => sum + m.content.length, 0);

// 更新游标
this.lastProcessedIndex = messages.length;
```

```typescript
  }
```

**Prompt 核心规则**:

```

1. span 必须是用户原话的"连续子串"（原文复制，不能改写）
2. sourceText 必须包含 span
3. 不允许改写、总结、推断

❌ 模型推断（如："擅长摄影"、"会使用招聘网站"）
❌ 常识 / 世界知识（如："杭州夏天很热"）
❌ 对话任务 / 短期计划（如："正在找工作"、"准备买房"）
❌ AI生成内容（只能基于用户原话）
❌ 问题或疑问句（如："你喜欢什么？"）
```

**SafeExtract (安全验证层)**:

#### 4.1 fuzzyMatch (模糊匹配)

**问题**: 模型（Qwen 2.5 3B）经常改写原文，导致 span 与 sourceText 不完全匹配。

**解决方案**: 多策略模糊匹配

```typescript
function fuzzyMatch(source: string, span: string): { matched: boolean; correctedSpan?: string } {
  const normalizedSource = normalizeForMatch(source);
  let normalizedSpan = normalizeForMatch(span);
  
  // 1. 移除末尾标点符号
  normalizedSpan = normalizedSpan.replace(/[.?!！？，,；;：:]+$/, '');
  
  // 2. 直接匹配
  if (normalizedSource.includes(normalizedSpan)) {
    return { matched: true, correctedSpan: normalizedSpan };
  }
  
  // 3. 前缀移除：如果 span 以 "我"、"其实"、"虽然" 开头，尝试移除后再匹配
  const prefixes = ['我', '我的', '用户', '我们', '其实', '就是', '虽然', '现在'];
  for (const prefix of prefixes) {
    if (normalizedSpan.startsWith(prefix)) {
      const spanWithoutPrefix = normalizedSpan.slice(prefix.length);
      if (spanWithoutPrefix.length >= 2 && normalizedSource.includes(spanWithoutPrefix)) {
        return { matched: true, correctedSpan: spanWithoutPrefix };
      }
    }
  }
  
  // 4. 前缀补全：尝试添加前缀来匹配
  for (const prefix of prefixes) {
    const spanWithPrefix = prefix + normalizedSpan;
    if (normalizedSource.includes(spanWithPrefix)) {
      return { matched: true, correctedSpan: spanWithPrefix };
    }
  }
  
  // 5. 后缀补全：尝试添加后缀来匹配
  const suffixes = ['的', '了', '着', '过'];
  for (const suffix of suffixes) {
    const spanWithSuffix = normalizedSpan + suffix;
    if (normalizedSource.includes(spanWithSuffix)) {
      return { matched: true, correctedSpan: spanWithSuffix };
    }
  }
  
  // 6. 核心模式提取：从 "住在杭州" 中提取 "杭州"
  const corePatterns = [
    /住在([\u4e00-\u9fa5]+)/,
    /在([\u4e00-\u9fa5]+工作)/,
    /是([\u4e00-\u9fa5]+)/,
    /有([\u4e00-\u9fa5]+)/,
    /喜欢([\u4e00-\u9fa5]+)/,
  ];
  for (const pattern of corePatterns) {
    const match = normalizedSpan.match(pattern);
    if (match && match[1]) {
      const core = match[1];
      if (core.length >= 2 && normalizedSource.includes(core)) {
        return { matched: true, correctedSpan: core };
      }
    }
  }
  
  // 7. 跨句子匹配：按标点符号分割 span，尝试匹配每个部分
  const words = normalizedSpan.split(/[，,。.！!？?；;：:]/).filter(w => w.trim().length >= 4);
  for (const word of words) {
    if (normalizedSource.includes(word.trim())) {
      return { matched: true, correctedSpan: word.trim() };
    }
  }
  
  return { matched: false };
}
```

#### 4.2 normalizeForMatch (标点符号统一)

```typescript
function normalizeForMatch(text: string): string {
  return text
    .replace(/（/g, "(")
    .replace(/）/g, ")")
    .replace(/，/g, ",")
    .replace(/。/g, ".")
    .replace(/：/g, ":")
    .replace(/；/g, ";")
    .replace(/！/g, "!")
    .replace(/？/g, "?")
    .replace(/[""]/g, '"')
    .replace(/['']/g, "'")
    .replace(/[———]/g, "-")
    .replace(/、/g, ",")
    .replace(/\s+/g, " ")
    .trim();
}
```

#### 4.3 hasSignalWord (信号词检查)

**三种通过路径**:

```typescript
function hasSignalWord(m: FilterInput): boolean {
  const span = m.span;

  // 路径1：强信号句
  const STRONG_SIGNALS = [
    "喜欢", "是", "有", "做", "用", "学", "看", "写",
    "想", "希望", "打算", "养", "住", "在", "去", "来",
    "爱", "会", "能", "要", "买", "玩", "吃", "听", "读"
  ];
  if (STRONG_SIGNALS.some(w => span.includes(w))) return true;

  // 路径2：技术词
  if (/^[a-zA-Z0-9+#.]+$/.test(span)) return true;

  // 路径3：preference/fact 绿色通道
  if (m.type === 'preference' || m.type === 'fact') {
    // 3.1 中文名词短语
    if (/^[\u4e00-\u9fa5]{2,10}$/.test(span)) {
      if (!GARBAGE_WORDS.includes(span)) return true;
    }

    // 3.2 地点模式
    const placePatterns = [
      /去[\u4e00-\u9fa5]+/,  
      /在[\u4e00-\u9fa5]+/,  
      /来[\u4e00-\u9fa5]+/,  
      /回[\u4e00-\u9fa5]+/,  
      /住[\u4e00-\u9fa5]+/,  
    ];
    if (placePatterns.some(p => p.test(span))) return true;

    // 3.3 时间模式
    const timePatterns = [
      /明年/, /今年/, /去年/, /周末/, /每天/, /每周/,
      /早上/, /晚上/, /周末/, /假期/, /三个月/, /三年/
    ];
    if (timePatterns.some(p => p.test(span))) return true;

    // 3.4 名词模式
    const nounPatterns = [
      /猫/, /狗/, /宠物/, /公司/, /工作/, /家/, /朋友/,
      /吉他/, /咖啡/, /书/, /电影/, /音乐/, /摄影/,
      /闺蜜/, /室友/, /奶奶/, /爷爷/, /父母/
    ];
    if (nounPatterns.some(p => p.test(span))) return true;
  }

  // 路径4：identity 特殊处理
  if (m.type === 'identity') {
    if (IDENTITY_KEYWORDS.some(k => span.includes(k))) return true;
    if (IDENTITY_ACTIONS.some(k => span.includes(k))) return true;
  }

  return false;
}
```

```typescript
function removeShortTermTask(m: FilterInput): boolean {
  const shortTimeWords = [
    "下周", "下个月", "明天", "后天", "这周", "这个月", "最近", "近期"
  ];
  
  const eventWords = [
    "过生日", "生日", "结婚", "搬家", "出差", "面试", "考试", "旅行",
    "约会", "聚餐", "开会", "出差", "放假", "回家"
  ];
  
  const hasShortTime = shortTimeWords.some(word => m.span.includes(word));
  const hasEvent = eventWords.some(word => m.span.includes(word));
  
  if (hasShortTime && hasEvent) {
    console.warn('[MemoryFilter] Rejected: short-term event detected');
    return false;
  }
  
  const taskKeywords = [
    "正在", "计划", "打算", "准备", "即将", "将要"
  ];
  
  return !taskKeywords.some(word => m.span.includes(word));
}
```

#### 4.6 deduplicate (语义去重)

```typescript
function deduplicate(m: FilterInput, index: number, arr: FilterInput[]): boolean {
  const normalizedContent = semanticNormalize(m.span);
  
  if (normalizedContent.length < 4) return false;
  
  return index === arr.findIndex(x => {
    if (x.type !== m.type) return false;
    
    const xNormalized = semanticNormalize(x.span);
    
    // 1. 完全匹配
    if (xNormalized === normalizedContent) return true;
    
    // 2. 包含关系
    if (xNormalized.includes(normalizedContent) || normalizedContent.includes(xNormalized)) {
      return true;
    }
    
    // 3. 相似度 > 0.8
    const similarity = calculateSimilarity(normalizedContent, xNormalized);
    return similarity > 0.8;
  });
}

function calculateSimilarity(a: string, b: string): number {
  if (a === b) return 1;
  if (a.length === 0 || b.length === 0) return 0;
  
  const longer = a.length > b.length ? a : b;
  const shorter = a.length > b.length ? b : a;
  
  // 包含关系
  if (longer.includes(shorter)) {
    return shorter.length / longer.length;
  }
  
  // 字符重叠
  let commonChars = 0;
  const shorterSet = new Set(shorter.split(''));
  for (const char of longer) {
    if (shorterSet.has(char)) commonChars++;
  }
  
  return commonChars / longer.length;
}
```

### 5. ReActEngine (对话历史截断)

**文件**: `src/agent/runtime/ReActEngine.ts`

**职责**: 截断对话历史，确保不超过模型上下文限制

**🔥 关键修复**: 确保所有路径都执行 user 开头检查，解决 Qwen 模型报错 "No user query found"。

```typescript
private truncateConversationHistory(
  history: ConversationMessage[],
  systemPromptLength: number
): ConversationMessage[] {
  const MAX_MODEL_TOKENS = 20000;
  const RESERVE_FOR_TOOLS = 2000;
  const RESERVE_FOR_RESPONSE = 2000;
  const MAX_CONTEXT_TOKENS = MAX_MODEL_TOKENS - RESERVE_FOR_TOOLS - RESERVE_FOR_RESPONSE;
  const AVG_CHARS_PER_TOKEN = 2;
  const MAX_CONTEXT_CHARS = MAX_CONTEXT_TOKENS * AVG_CHARS_PER_TOKEN;
  const MIN_MESSAGES_TO_KEEP = 4;
  const MAX_MESSAGES = 20;

  const availableChars = MAX_CONTEXT_CHARS - systemPromptLength;

  // 1. 限制最大消息数
  if (history.length > MAX_MESSAGES) {
    history = history.slice(-MAX_MESSAGES);
  }

  let result: ConversationMessage[];
  
  // 2. 检查是否需要截断
  let totalChars = history.reduce((sum, m) => sum + (m.content?.length || 0), 0);
  
  if (totalChars <= availableChars) {
    result = [...history];
  } else {
    // 3. 从最新消息开始保留
    result = [];
    let currentChars = 0;
    const recentMessages = [...history].reverse();

    for (const msg of recentMessages) {
      const msgLength = msg.content?.length || 0;
      if (currentChars + msgLength <= availableChars || result.length < MIN_MESSAGES_TO_KEEP) {
        result.unshift(msg);
        currentChars += msgLength;
      } else {
        break;
      }
    }
  }

  // 🔥 4. 确保历史消息以 user 开头（Qwen 模型要求）
  while (result.length > 0 && result[0].role !== 'user') {
    console.log(`[ReActEngine] 移除开头的非 user 消息: ${result[0].role}`);
    result.shift();
  }

  return result;
}
```
