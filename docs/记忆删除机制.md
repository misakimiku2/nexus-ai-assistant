## 记忆删除机制
### 删除条件
记忆删除需要满足以下条件：

阶段 条件 说明 1. 标记不活跃 score < 0.3 且 is_active = 1 记忆被标记为不活跃 2. 永久删除 score < 0.1 且 is_active = 0 且 不活跃超过7天 记忆被永久删除

### 衰减计算
衰减公式：

```
new_score = score × e^(-decay × 
days)
```
### 0.9 评分记忆的存活时间
假设 decay = 0.01 （fact 类型默认值）：

第一阶段：从 0.9 衰减到 0.3

```
0.3 = 0.9 × e^(-0.01 × days)
days = ln(0.333) / (-0.01) ≈ 110 天
```
第二阶段：从 0.3 衰减到 0.1

```
0.1 = 0.3 × e^(-0.01 × days)
days = ln(0.333) / (-0.01) ≈ 110 天
```
第三阶段：不活跃等待期

```
7 天
```
总计：约 227 天（约 7.5 个月）

### 不同类型记忆的存活时间
记忆类型 decay 从 0.9 到删除的时间 identity 0.001 约 2270 天（6.2 年） skill 0.002 约 1135 天（3.1 年） constraint 0.003 约 757 天（2.1 年） preference 0.005 约 454 天（1.2 年） fact 0.01 约 227 天（7.5 个月） task 0.02 约 114 天（3.8 个月）

### 加速删除的因素
1. 从未被访问 ：没有访问奖励（ access_bonus ）
2. 低重要性 ：初始 importance 较低
3. 高 decay 值 ：任务类型记忆衰减更快
### 延长记忆寿命的因素
1. 被检索到 ：每次检索增加 access_count ，获得访问奖励
2. 高重要性 ：初始 importance 较高
3. 低 decay 值 ：身份类型记忆衰减最慢

### 总结 ：一个 0.9 评分的 fact 类型记忆，如果从未被访问，大约需要 7.5 个月 才会被永久删除。如果是 identity 类型，则需要 6 年以上 。
