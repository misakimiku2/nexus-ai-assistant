## 3. 功能模块与 Rust 后端对接清单

以下是当前需要重点对接 Rust 后端的功能模块。这些功能目前在前端仅使用了 Mock 数据或占位逻辑。

### 3.1 核心 AI 交互模块
- **功能描述：** 前端发送 Prompt，调用本地 LM Studio API。
- **对接任务：**
    - [ ] 在 `src-tauri/src/main.rs` 中实现 `invoke` 命令 `call_llm`。
    - [ ] 使用 Rust 的 `reqwest` 库处理 HTTP 请求，确保与 LM Studio 的通信。
    - [ ] 实现流式响应 (Streaming) 的处理逻辑，确保前端能实时展示 AI 输出。
- **优先级：** 高

### 3.2 本地文件系统管理
- **功能描述：** 读取、保存、删除本地配置文件或用户生成的文档。
- **对接任务：**
    - [ ] 使用 Tauri 的 `tauri::api::fs` 或 Rust 的 `std::fs` 模块。
    - [ ] 封装 `save_file` 和 `load_file` 命令，确保路径安全（防止路径遍历漏洞）。
- **优先级：** 中

### 3.3 本地数据持久化 (数据库)
- **功能描述：** 存储用户的对话历史、偏好设置等。
- **对接任务：**
    - [ ] 在 `Cargo.toml` 中添加 `sqlx` 或 `rusqlite` 依赖。
    - [ ] 初始化 SQLite 数据库，定义 Schema。
    - [ ] 编写 Rust 命令，实现 CRUD 操作。
- **优先级：** 中

### 3.4 系统级集成 (OS Integration)
- **功能描述：** 窗口控制、系统托盘、文件拖拽处理等。
- **对接任务：**

    - [ ] 在 Rust 中实现相应的事件监听或命令调用。
- **优先级：** 低
