根据用户反馈和代码分析，存在四个问题：

### 问题1：推理步骤嵌套冗余
在 [ChatView.tsx:475-513](file:///c:\Users\Misaki\Desktop\git\nexus-ai-assistant\src\components\ChatView.tsx#L475-L513) 中，推理步骤被包裹在一个单独的 `<div>` 中，标题是"推理步骤"。用户希望直接把这些步骤放到思考过程中，不需要再套一个"推理步骤"标题。

当前推理步骤是在内容完全累积后才添加的，用户希望推理步骤也能流式输出。

**当前结构：**
```
思考过程 (折叠卡片)
├── thinking 内容 (单独渲染)
└── 推理步骤 (嵌套div)
    ├── 思考: xxx

    └── 观察: xxx
```

**期望结构：**
```
思考过程 (折叠卡片) - 流式输出
├── 思考: thinking内容 (如果有) - 流式
├── 思考: reasoningStep内容 (如果有) - 流式
├── 行动: xxx
└── 观察: xxx
```

```typescript
private updateReasoningStep(stepId: string, content: string): void {
  const step = this.state.reasoningSteps.find(s => s.id === stepId);
  if (step) {
    step.content = content;
    this.context.onReasoningStepUpdate?.(step);
  }
}
```

**修改 callLLMStream 方法：**
```typescript
private async callLLMStream(messages: ConversationMessage[]): Promise<LLMResponse> {
  // 创建一个初始的思考步骤
  const thoughtStepId = `thought_${Date.now()}`;
  this.addReasoningStep('thought', '', thoughtStepId);
  
  let accumulatedContent = '';
  let accumulatedReasoningContent = '';
  
  for await (const chunk of streamLLMWithTools(this.config, messages)) {
    if (chunk.type === 'reasoning_content') {
      accumulatedReasoningContent += chunk.data;
      this.updateReasoningStep(thoughtStepId, accumulatedReasoningContent);
    } else if (chunk.type === 'content') {
      accumulatedContent += chunk.data;
    }
    // ... 其他处理
  }
  
  // 标记流式结束
  this.finalizeReasoningStep(thoughtStepId);
  
  return { ... };
}
```
