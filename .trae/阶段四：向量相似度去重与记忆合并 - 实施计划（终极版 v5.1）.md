# 阶段四：向量相似度去重与记忆合并 - 实施计划（终极版 v5.1）

## 核心目标

将简单规则去重升级为**分层向量相似度去重**，复用 Retrieval 缩小候选集，使用 LLM 进行智能合并，并通过权重提升机制处理语义重复。

***

## 系统级设计原则

### 1. 去重分层（修正）
```
┌─────────────────────────────────────────────────────────────┐
│                    Candidate 阶段                            │
│  目标：标记相似记忆，供 UI 展示                                │
│  策略：轻量语义去重（只标记，不执行任何操作）                    │
│  输出：候选记忆 + 相似记忆列表（供用户参考）                     │
│  ⚠️ 禁止：Candidate 阶段不执行 boost/merge/reject            │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Accept 阶段                               │
│  目标：精确判断并执行操作                                      │
│  策略：精确向量去重 + Pipeline 执行（Conflict → Merge → Boost）│
│  输出：DedupDecision（包含所有 targets）                      │
└─────────────────────────────────────────────────────────────┘
```

### 2. Pipeline 执行策略（关键修正）
```
❌ 错误做法（丢信息）：
   if !conflict_targets.is_empty() {
       ResolveConflict  // 只执行这个，其他丢了
   } else if !boost_targets.is_empty() {
       BoostExisting
   } else if !merge_targets.is_empty() {
       Merge
   }

✅ 正确做法（Pipeline）：
   pub struct DedupDecision {
       pub boost_targets: Vec<BoostTarget>,
       pub merge_targets: Vec<MergeTarget>,
       pub conflict_targets: Vec<ConflictTarget>,
   }
   
   // 执行顺序（Pipeline）：
   // 1. 先 resolve conflict
   // 2. 再 merge
   // 3. 最后 boost
   ```
### 3. Working Set 机制（架构级修正）
```
❌ 错误做法（状态污染）：
   // resolve_conflicts → 直接修改 storage
   update_memory_with_version()
   
   // 然后 merge → 读 storage（读到的是已修改的 memory）
   multi_source_merge()
   
   // 问题：merge 阶段读到的是"已经被改过的 memory"

✅ 正确做法（Working Set）：
   // 1. 加载工作副本到内存
   let mut working_set = WorkingSet::new();
   working_set.load_from_storage(&memory_ids);
   
   // 2. 所有操作在内存中进行
   working_set.resolve_conflicts(...);  // 修改 working_set
   working_set.merge(...);              // 使用 working_set（不是 storage）
   working_set.boost(...);              // 修改 working_set
   
   // 3. 最后统一写回 storage
   working_set.commit_to_storage(&storage);
   
   // 核心思想：所有步骤 → 内存态处理 → 最后 commit
   ```
### 4. Conflict → Merge 去重保护（架构级修正）
```
❌ 错误做法（碎片记忆）：
   // conflict resolve 后，memory 已经变了
   // 但 merge_targets 还是原来计算的，没有重新计算
   
   // 结果：系统会产生"碎片记忆"，merge 永远不彻底

✅ 正确做法（重新计算 merge pool）：
   // Step 1: resolve conflict
   let resolved_memories = working_set.resolve_conflicts(...);
   
   // Step 2: 把 conflict 更新后的 memory 加入 merge pool
   merge_pool.extend(resolved_memories);
   
   // Step 3: 重新计算 merge_targets（基于更新后的 working_set）
   let new_merge_targets = recalculate_merge_targets(&working_set, &candidate);
   
   // Step 4: 执行 merge
   working_set.merge(new_merge_targets, ...);
   ```
### 5. Boost 递减收益机制（架构级修正）
``` 
❌ 错误做法（无限膨胀）：
   importance += boost_amount
   score += boost_amount
   // 高频 memory 会变成"永远无法被替代的霸权记忆"

✅ 正确做法（递减收益）：
   importance = importance * 0.95 + boost_amount
   // boost 必须"递减收益"，防止霸权记忆
   ```
 ### 6. 可追溯记忆系统（关键新增）
 ```
   pub struct MemoryItem {
    pub id: String,
    pub content: String,
    pub version: i32,           // 版本号
    pub parent_ids: Vec<String>, // 新增：父记忆 ID（来源追溯）
    // ...
}

// 用途：
// 1. 可视化 memory evolution（超有价值）
// 2. debug LLM merge 问题
// 3. 做"记忆回滚树"

// 示例：
// A + B + C → D
// D.parent_ids = [A.id, B.id, C.id]
// D.source_ids = [A.id, B.id, C.id]（已废弃，用 parent_ids 替代）
```
### 7. 冲突检测优化（关键修正）
``` 
❌ 错误做法（O(k) LLM 调用）：
   for similar in similar_memories {
       detect_conflict() // 每条都调用 LLM
   }
   // top_k = 10 → 最多 10 次 LLM 调用

✅ 正确做法（限制 LLM 调用）：
   // 策略 1：只对高相似度做冲突检测
   if similarity > 0.80 {
       detect_conflict()
   }
   
   // 策略 2：只对 top 3 做冲突检测
   let conflict_candidates: Vec<_> = similar_memories.iter()
       .filter(|s| s.similarity >= 0.75)
       .take(3)
       .collect();
```
 
### 8. 多源合并（关键修正）
``` 
❌ 错误做法（链式合并，顺序影响结果）：
   ((candidate + A) + B) + C

✅ 正确做法（多源合并，一次性合并）：
   MergeRequest {
       existing_memories: Vec<MemoryItem>,  // 所有待合并记忆
       candidate: CandidateMemory
   }
   
   LLM prompt：
   请将以下多条记忆合并为一条：
   - A: xxx
   - B: xxx
   - C: xxx
   - candidate: xxx
```
### 9. 收敛判断条件（关键修正）
```    
❌ 错误做法（条件不明确）：
   convergence_threshold = 0.85
   // 什么叫收敛？没定义

✅ 正确做法（明确定义收敛条件）：
   // 条件 1：与现有记忆的最大相似度低于阈值
   if max_similarity < threshold {
       stop  // 收敛
   }
   
   // 条件 2：合并内容变化不大（稳定）
   let content_similarity = cosine_similarity(
       &previous_content_embedding,
       &merged_content_embedding
   );
   if content_similarity > 0.95 {
       stop  // 内容已稳定
   }
``` 
### 10. 逻辑删除（关键修正）
```     
❌ 错误做法（硬删除，不可恢复）：
   delete_memory()

✅ 正确做法（逻辑删除）：
   is_active = false
   
   // 已有 only_active: true，所以逻辑删除不影响检索
```
### 11. 时间维度（关键修正）
``` 
// 综合评分公式
score = importance * recency_weight * access_factor

// 时间衰减因子
recency_weight = exp(-days_since_access / 30.0)
```
### 12. Merge 后反向去重（关键修正）
```     
❌ 错误做法（产生重复记忆）：
   merge → 创建新 memory → 结束
   // 新 memory 可能与 working set 中其他 memory 高度重复

✅ 正确做法（反向去重）：
   merge → 检查 merged_content 与 working set 相似度
   if max_similarity > accept_exact_threshold {
       // ❗关键：不删除旧记忆，不创建新记忆
       // 只做一件事：boost 最相似的记忆
       return MergeResult { merged: false, ... };
   } else {
       // 创建新 memory
       return MergeResult { merged: true, ... };
   }
```
### 13. Merge 后不"误杀"原始记忆（严重修正）
```     
   ❌ 错误做法（误杀正确记忆）：
   if max_similarity > threshold {
       mark_deleted(merge_targets);  // ❌ 删除原始记忆
       boost(most_similar);
   }
   // 后果：原始信息丢失，只保留不稳定的 merged 版本

✅ 正确做法（保护原始记忆）：
   if max_similarity > threshold {
       // ❗不要删除 merge_targets
       // ❗也不要创建新 memory
       // 只做一件事：boost 最相似的记忆
       boost(most_similar);
       return MergeResult { merged: false, ... };
   }
   
   // 核心原则：已有记忆够好 → 不产生新记忆，也不删除旧记忆
```
### 14. WorkingSet 隔离 candidate（关键修正）
```   
 
   ❌ 错误做法（污染计算）：
   for (id, wm) in working_set.memories.iter() {
       // 全部一起算相似度
       // merge 会"和自己比较"
   }

✅ 正确做法（隔离 merge_targets）：
   let merge_target_ids: HashSet<String> = merge_targets.iter()
       .map(|t| t.memory_id.clone())
       .collect();
   
   for (id, wm) in working_set.memories.iter() {
       if wm.is_deleted { continue; }
       
       // ❗关键：排除 merge_targets 自己
       if merge_target_ids.contains(id) { continue; }
       
       // 计算相似度
   }
   
   // 核心原则：去重只能针对"稳定存量"，不能对"正在变化的数据"做判断
```
### 15. parent_ids 完整性（关键修正）
```

❌ 错误做法（缺少 candidate）：
   parent_ids = merge_targets.map(|t| t.memory_id)
   // 缺少 candidate.id

✅ 正确做法（包含所有来源）：
   let mut parent_ids = merge_targets.map(|t| t.memory_id).collect();
   parent_ids.push(candidate.id.clone());  // ⚠️ 必须加
```
### 16. MergeResult.merged 字段（关键修正）
```
   ❌ 错误做法（无法区分是否创建新记忆）：
   pub struct MergeResult {
       pub merged_content: String,
       // 没有 merged 字段
   }
   // UI / 上层无法判断是否发生了 merge

✅ 正确做法（显式状态）：
   pub struct MergeResult {
       pub merged_content: String,
       pub merged: bool,  // ❗关键：表示是否创建了新记忆
   }
   
   // 使用：
   if max_similarity > threshold {
       return MergeResult { merged: false, ... };  // 没有创建新记忆
   } else {
       return MergeResult { merged: true, ... };   // 创建了新记忆
   }
   
   // 核心原则："是否产生新 memory"必须是显式状态，而不是靠猜
```
### 17. merged: false 时 merged_content 是"污染数据"（关键修正）
``` 

   ❌ 错误做法（返回无效中间产物）：
   if max_similarity > threshold {
       return MergeResult {
           merged_content: result.merged_content,  // ⚠️ LLM 生成但未入库
           merged: false,
       };
   }
   // 风险：上层可能把它当成"有效记忆"使用

✅ 正确做法（不返回无效数据）：
   if max_similarity > threshold {
       return MergeResult {
           merged_content: String::new(),  // ❗关键：不返回无效的中间产物
           merged_importance: 0.0,         // ❗关键：无效数据
           merged: false,
       };
   }
   
   // 核心原则：未进入 storage 的内容 = 不存在
```
### 18. 返回值必须 = 实际写入的数据（关键修正）
```

❌ 错误做法（返回值与实际数据不一致）：
   let mut parent_ids = merge_targets + candidate.id;
   create_memory(parent_ids);  // ✅ 写入完整
   
   return MergeResult {
       parent_ids: merge_targets,  // ❌ 丢了 candidate.id
   };
   // 后果：上层看到的 graph ≠ 实际 storage 中的 graph

✅ 正确做法（统一返回值）：
   let mut parent_ids: Vec<String> = merge_targets
       .iter()
       .map(|t| t.memory_id.clone())
       .collect();
   parent_ids.push(candidate.id.clone());
   
   create_memory(parent_ids.clone());  // ✅ 写入完整
   
   return MergeResult {
       parent_ids,  // ❗关键：必须用同一份（包含 candidate.id）
   };
   
   // 核心原则：返回值必须 = 实际写入的数据
```
### 19. Working Set 性能优化（关键修正）
```
❌ 错误做法（全表扫描）：
   let all_memories = storage.get_all_memories().await?;
   // O(n) 全表扫描

✅ 正确做法（按 ID 查询）：
   let memories = storage.get_memories_by_ids(&memory_ids).await?;
   // O(k) 按候选集大小查询
```
### 20. Embedding 预计算（关键修正）
```
❌ 错误做法（重复计算）：
   for target in merge_targets {
       let embedding = self.embedding.embed(&candidate.content).await?;
       // 每次循环都计算
   }

✅ 正确做法（预计算）：
   let candidate_embedding = self.embedding.embed(&candidate.content).await?;
   // 预计算一次，复用
   for target in merge_targets {
       // 使用 candidate_embedding
   }
```

### 4.2 后端：Working Set（内存态操作）
文件: src-tauri/src/memory/working_set.rs（新建）
```rust
use std::collections::HashMap;
use crate::models::{MemoryItem, CandidateMemory, ConflictTarget, MergeTarget, BoostTarget, BoostConfig};
use crate::memory::embedding::EmbeddingService;
use crate::memory::storage::MemoryStorage;
use crate::memory::conflict::{ConflictDetector, ConflictResolveRequest, ConflictResolveResult};
use crate::memory::merge::{MergeService, MultiSourceMergeRequest, MergeResult};

pub struct WorkingMemory {
    pub memory: MemoryItem,
    pub is_modified: bool,
    pub is_deleted: bool,
}

pub struct WorkingSet {
    memories: HashMap<String, WorkingMemory>,
    embedding: EmbeddingService,
    boost_config: BoostConfig,
}

impl WorkingSet {
    pub fn new(embedding: EmbeddingService) -> Self {
        Self {
            memories: HashMap::new(),
            embedding,
            boost_config: BoostConfig::default(),
        }
    }

    pub fn with_config(embedding: EmbeddingService, boost_config: BoostConfig) -> Self {
        Self {
            memories: HashMap::new(),
            embedding,
            boost_config,
        }
    }

    // 关键修正：使用 get_memories_by_ids 而不是 get_all_memories
    // 避免 O(n) 全表扫描
    pub async fn load_from_storage(&mut self, storage: &MemoryStorage, memory_ids: &[String]) -> Result<(), Box<dyn std::error::Error>> {
        // 关键修正：只加载候选集，不扫全库
        let memories = storage.get_memories_by_ids(memory_ids).await?;
        
        for memory in memories {
            self.memories.insert(memory.id.clone(), WorkingMemory {
                memory,
                is_modified: false,
                is_deleted: false,
            });
        }
        
        log::info!("[WorkingSet] 加载 {} 条记忆到工作集（按 ID 加载）", self.memories.len());
        Ok(())
    }

    pub fn get_memory(&self, id: &str) -> Option<&MemoryItem> {
        self.memories.get(id).map(|wm| &wm.memory)
    }

    pub fn get_memory_mut(&mut self, id: &str) -> Option<&mut MemoryItem> {
        self.memories.get_mut(id).map(|wm| {
            wm.is_modified = true;
            &mut wm.memory
        })
    }

    pub fn add_memory(&mut self, memory: MemoryItem) {
        self.memories.insert(memory.id.clone(), WorkingMemory {
            memory,
            is_modified: true,
            is_deleted: false,
        });
    }

    pub fn mark_deleted(&mut self, id: &str) {
        if let Some(wm) = self.memories.get_mut(id) {
            wm.is_deleted = true;
            wm.is_modified = true;
        }
    }

    pub fn get_all_active(&self) -> Vec<&MemoryItem> {
        self.memories.values()
            .filter(|wm| !wm.is_deleted && wm.memory.is_active)
            .map(|wm| &wm.memory)
            .collect()
    }

    pub fn get_modified(&self) -> Vec<&MemoryItem> {
        self.memories.values()
            .filter(|wm| wm.is_modified && !wm.is_deleted)
            .map(|wm| &wm.memory)
            .collect()
    }

    pub fn get_deleted_ids(&self) -> Vec<String> {
        self.memories.values()
            .filter(|wm| wm.is_deleted)
            .map(|wm| wm.memory.id.clone())
            .collect()
    }

    // 关键修正：resolve conflicts 在内存中进行
    pub async fn resolve_conflicts(
        &mut self,
        candidate: &CandidateMemory,
        conflict_targets: &[ConflictTarget],
        conflict_detector: &ConflictDetector,
    ) -> Result<Vec<ConflictResolveResult>, Box<dyn std::error::Error>> {
        let mut results = Vec::new();
        
        for target in conflict_targets {
            let existing = self.get_memory(&target.memory_id)
                .ok_or("Memory not found in working set")?
                .clone();
            
            let request = ConflictResolveRequest {
                existing: existing.clone(),
                candidate: candidate.clone(),
                conflict_type: target.conflict_type.clone(),
            };
            
            let resolved = conflict_detector.resolve_conflict(request).await?;
            
            // 更新 working set 中的 memory（不是 storage）
            if let Some(memory) = self.get_memory_mut(&target.memory_id) {
                memory.content = resolved.resolved_content.clone();
                memory.importance = resolved.resolved_importance;
                memory.score = resolved.resolved_importance;
                memory.version += 1;
                memory.updated_at = chrono::Utc::now().timestamp();
                memory.last_accessed_at = chrono::Utc::now().timestamp();
                
                // 更新 embedding
                let emb = self.embedding.embed(&memory.content).await?;
                memory.embedding = Some(emb);
            }
            
            results.push(ConflictResolveResult {
                resolved_content: resolved.resolved_content,
                resolved_importance: resolved.resolved_importance,
                resolve_reason: resolved.resolve_reason,
                parent_id: target.memory_id.clone(),
            });
        }
        
        log::info!("[WorkingSet] 解决 {} 个冲突", results.len());
        Ok(results)
    }

    // 关键修正：递减收益的 boost
    pub fn boost_memories(&mut self, targets: &[BoostTarget]) -> Vec<MemoryItem> {
        let mut boosted = Vec::new();
        
        for target in targets {
            if let Some(memory) = self.get_memory_mut(&target.memory_id) {
                // 关键修正：递减收益
                // importance = importance * 0.95 + boost_amount
                memory.importance = (memory.importance * self.boost_config.decay_factor + target.boost_amount)
                    .min(self.boost_config.max_importance);
                memory.score = memory.importance;
                memory.access_count += 1;
                memory.last_accessed_at = chrono::Utc::now().timestamp();
                memory.version += 1;
                memory.updated_at = chrono::Utc::now().timestamp();
                
                boosted.push(memory.clone());
            }
        }
        
        log::info!("[WorkingSet] 提升 {} 条记忆权重（递减收益）", boosted.len());
        boosted
    }

    // 关键修正：最后统一写回 storage
    pub async fn commit_to_storage(&self, storage: &MemoryStorage) -> Result<CommitResult, Box<dyn std::error::Error>> {
        let mut updated_count = 0;
        let mut deleted_count = 0;
        let mut created_count = 0;
        
        for wm in self.memories.values() {
            if wm.is_deleted {
                // 逻辑删除
                let mut memory = wm.memory.clone();
                memory.is_active = false;
                memory.updated_at = chrono::Utc::now().timestamp();
                storage.add_memory(memory).await?;
                deleted_count += 1;
            } else if wm.is_modified {
                // 更新或创建
                storage.add_memory(wm.memory.clone()).await?;
                if wm.memory.version == 1 {
                    created_count += 1;
                } else {
                    updated_count += 1;
                }
            }
        }
        
        log::info!("[WorkingSet] 提交完成: 创建 {} 条, 更新 {} 条, 删除 {} 条", 
            created_count, updated_count, deleted_count);
        
        Ok(CommitResult {
            created_count,
            updated_count,
            deleted_count,
        })
    }
}
```

```rust
pub fn calculate_recency_weight(last_accessed_at: i64, config: &RecencyConfig) -> f32 {
    let now = chrono::Utc::now().timestamp();
    let days_since_access = (now - last_accessed_at) as f32 / (24.0 * 3600.0);
    
    (-days_since_access / config.half_life_days).exp()
}

pub fn calculate_score(memory: &MemoryItem, config: &RecencyConfig) -> f32 {
    let recency_weight = calculate_recency_weight(memory.last_accessed_at, config);
    let access_factor = 1.0 + (memory.access_count as f32 * 0.05);
    
    memory.importance * recency_weight * access_factor
}

pub fn calculate_all_scores(memories: &[MemoryItem], config: &RecencyConfig) -> Vec<(String, f32)> {
    memories.iter()
        .map(|m| (m.id.clone(), calculate_score(m, config)))
        .collect()
}

pub fn should_deactivate(memory: &MemoryItem, config: &DeletionConfig) -> bool {
    if memory.importance >= config.min_importance {
        return false;
    }
    
    let now = chrono::Utc::now().timestamp();
    let days_since_access = (now - memory.last_accessed_at) / (24 * 3600);
    
    days_since_access > config.max_inactive_days
}
```

    pub async fn detect_conflicts_batch(
        &self,
        candidate_content: &str,
        similar_memories: &[SimilarMemory],
    ) -> Result<Vec<ConflictTarget>, Box<dyn std::error::Error>> {
        let mut conflict_targets = Vec::new();
        
        let candidates: Vec<_> = similar_memories.iter()
            .filter(|s| s.similarity >= self.config.min_similarity)
            .take(self.config.max_candidates)
            .collect();
        
        log::info!("[ConflictDetector] 冲突检测候选: {} 条 (从 {} 条中筛选)", 
            candidates.len(), similar_memories.len());
        
        for similar in candidates {
            let conflict = self.detect_conflict(candidate_content, &similar.memory.content).await?;
            
            if let Some(conflict_type) = conflict {
                conflict_targets.push(ConflictTarget {
                    memory_id: similar.memory.id.clone(),
                    similarity: similar.similarity,
                    conflict_type,
                });
            }
        }
        
        Ok(conflict_targets)
    }

    pub async fn detect_conflict(
        &self,
        content_a: &str,
        content_b: &str,
    ) -> Result<Option<ConflictType>, Box<dyn std::error::Error>> {
        let prompt = CONFLICT_DETECTION_PROMPT
            .replace("{content_a}", content_a)
            .replace("{content_b}", content_b);
        
        let response = self.llm_client.generate(&prompt).await?;
        let result = self.parse_detection_response(&response)?;
        
        if result.has_conflict {
            Ok(Some(result.conflict_type))
        } else {
            Ok(None)
        }
    }

    fn parse_detection_response(&self, response: &str) -> Result<ConflictDetectionResult, Box<dyn std::error::Error>> {
        let trimmed = response.trim();
        let json_str = extract_json(trimmed)?;
        let parsed: serde_json::Value = serde_json::from_str(json_str)?;
        
        let conflict_type = match parsed["conflict_type"].as_str() {
            Some("preference") => ConflictType::Preference,
            Some("fact") => ConflictType::Fact,
            Some("status") => ConflictType::Status,
            _ => return Ok(ConflictDetectionResult { has_conflict: false, conflict_type: None, reason: None }),
        };
        
        Ok(ConflictDetectionResult {
            has_conflict: parsed["has_conflict"].as_bool().unwrap_or(false),
            conflict_type: Some(conflict_type),
            reason: parsed["reason"].as_str().map(|s| s.to_string()),
        })
    }

    pub async fn resolve_conflict(
        &self,
        request: ConflictResolveRequest,
    ) -> Result<ConflictResolveResult, Box<dyn std::error::Error>> {
        log::info!("[ConflictResolver] 开始解决冲突");
        
        let prompt = CONFLICT_RESOLVE_PROMPT
            .replace("{type_a}", request.existing.memory_type.as_str())
            .replace("{content_a}", &request.existing.content)
            .replace("{importance_a}", &format!("{:.2}", request.existing.importance))
            .replace("{type_b}", &request.candidate.memory_type.as_str())
            .replace("{content_b}", &request.candidate.content)
            .replace("{importance_b}", &format!("{:.2}", request.candidate.importance))
            .replace("{conflict_type}", &format!("{:?}", request.conflict_type));
        
        match self.llm_client.generate(&prompt).await {
            Ok(response) => {
                match self.parse_resolve_response(&response) {
                    Ok(result) => Ok(result),
                    Err(_) => Ok(self.fallback_resolve(&request)),
                }
            }
            Err(_) => Ok(self.fallback_resolve(&request)),
        }
    }

    fn fallback_resolve(&self, request: &ConflictResolveRequest) -> ConflictResolveResult {
        log::info!("[ConflictResolver] 使用 fallback 解决冲突");
        
        ConflictResolveResult {
            resolved_content: format!("{}（已更新：{}）", request.existing.content, request.candidate.content),
            resolved_importance: request.candidate.importance,
            resolve_reason: "LLM 解决失败，使用简单拼接".to_string(),
            parent_id: request.existing.id.clone(),
        }
    }

    fn parse_resolve_response(&self, response: &str) -> Result<ConflictResolveResult, Box<dyn std::error::Error>> {

        Ok(ConflictResolveResult {
            resolved_content: parsed["resolved_content"].as_str().unwrap_or("").to_string(),
            resolved_importance: parsed["resolved_importance"].as_f64().unwrap_or(0.5) as f32,
            resolve_reason: parsed["resolve_reason"].as_str().unwrap_or("").to_string(),
            parent_id: String::new(),
        })
    }
}

fn extract_json(text: &str) -> Result<&str, Box<dyn std::error::Error>> {

        Ok(&trimmed[7..7 + end].trim())
    } else if trimmed.starts_with("```") {
        let end = trimmed[3..].find("```").unwrap_or(trimmed.len() - 3);
        Ok(&trimmed[3..3 + end].trim())
    } else {
        Ok(trimmed)
    }
}

```rust
        candidate: &CandidateMemory,
    ) -> Result<DedupDecision, Box<dyn std::error::Error>> {
        log::info!("[DedupService] Accept 阶段去重: {}", 
            candidate.content.chars().take(30).collect::<String>());
        
        let options = RetrievalOptions {
            top_k: self.config.retrieval_top_k,
            min_similarity: self.config.accept_partial_threshold,
            only_active: true,
            ..Default::default()
        };
        
        let retrieved = self.retriever.retrieve(&candidate.content, options).await?;
        
        if retrieved.is_empty() {
            log::info!("[DedupService] 无相似记忆，接受");
            return Ok(DedupDecision {
                boost_targets: vec![],
                merge_targets: vec![],
                conflict_targets: vec![],
                similar_memories: vec![],
                max_similarity: 0.0,
            });
        }
        
        let similar_memories: Vec<SimilarMemory> = retrieved
            .into_iter()
            .map(|r| SimilarMemory {
                memory: r.item,
                similarity: r.components.similarity,
            })
            .collect();
        
        let max_similarity = similar_memories.iter()
            .map(|s| s.similarity)
            .fold(0.0, f32::max);
        
        let decision = self.classify_all_similarities(&candidate, &similar_memories).await?;
        
        log::info!("[DedupService] Accept 阶段完成: boost={}, merge={}, conflict={}", 
            decision.boost_targets.len(),
            decision.merge_targets.len(),
            decision.conflict_targets.len());
        
        Ok(decision)
    }

    async fn classify_all_similarities(
        &self,
        candidate: &CandidateMemory,
        similar_memories: &[SimilarMemory],
    ) -> Result<DedupDecision, Box<dyn std::error::Error>> {
        let mut boost_targets: Vec<BoostTarget> = Vec::new();
        let mut merge_candidates: Vec<SimilarMemory> = Vec::new();
        
        for similar in similar_memories {
            if similar.similarity >= self.config.accept_exact_threshold {
                boost_targets.push(BoostTarget {
                    memory_id: similar.memory.id.clone(),
                    similarity: similar.similarity,
                    boost_amount: self.config.boost_amount,
                });
            } else if similar.similarity >= self.config.accept_partial_threshold {
                merge_candidates.push(similar.clone());
            }
        }
        
        let conflict_targets = self.conflict_detector
            .detect_conflicts_batch(&candidate.content, &merge_candidates)
            .await?;
        
        let conflict_ids: std::collections::HashSet<String> = conflict_targets.iter()
            .map(|c| c.memory_id.clone())
            .collect();
        
        let merge_targets: Vec<MergeTarget> = merge_candidates.iter()
            .filter(|s| !conflict_ids.contains(&s.memory.id))
            .map(|s| MergeTarget {
                memory_id: s.memory.id.clone(),
                similarity: s.similarity,
                memory_type: s.memory.memory_type.clone(),
            })
            .collect();
        
        let max_similarity = similar_memories.iter()
            .map(|s| s.similarity)
            .fold(0.0, f32::max);
        
        Ok(DedupDecision {
            boost_targets,
            merge_targets,
            conflict_targets,
            similar_memories: similar_memories.to_vec(),
            max_similarity,
        })
    }

    // 关键修正：使用 Working Set 执行 Pipeline
    pub async fn execute_pipeline(
        &self,
        candidate: &CandidateMemory,
        decision: DedupDecision,
    ) -> Result<PipelineResult, Box<dyn std::error::Error>> {
        log::info!("[DedupService] 开始执行 Pipeline（Working Set 模式）");
        
        let mut result = PipelineResult::default();
        
        // 关键修正：创建 Working Set
        let all_memory_ids: Vec<String> = decision.similar_memories.iter()
            .map(|s| s.memory.id.clone())
            .collect();
        
        let mut working_set = WorkingSet::with_config(
            self.embedding.clone(),
            self.boost_config.clone(),
        );
        working_set.load_from_storage(&self.storage, &all_memory_ids).await?;
        
        // Step 1: 解决冲突（在 Working Set 中）
        if !decision.conflict_targets.is_empty() {
            let conflict_result = working_set.resolve_conflicts(
                candidate,
                &decision.conflict_targets,
                &self.conflict_detector,
            ).await?;
            result.conflicts_resolved = conflict_result;
            
            // 关键修正：把 conflict 更新后的 memory 加入 merge pool
            // 重新计算 merge_targets（基于更新后的 working_set）
            let new_merge_targets = self.recalculate_merge_targets(
                &working_set,
                candidate,
                &decision.merge_targets,
            ).await?;
            
            // 执行 merge（使用更新后的 merge_targets）
            if !new_merge_targets.is_empty() {
                let merge_result = self.multi_source_merge_in_working_set(
                    &mut working_set,
                    candidate,
                    &new_merge_targets,
                ).await?;
                result.merged = Some(merge_result);
            }
        } else if !decision.merge_targets.is_empty() {
            // Step 2: 多源合并（如果没有冲突）
            let merge_result = self.multi_source_merge_in_working_set(
                &mut working_set,
                candidate,
                &decision.merge_targets,
            ).await?;
            result.merged = Some(merge_result);
        }
        
        // Step 3: 提升权重（递减收益）
        if !decision.boost_targets.is_empty() {
            let boosted = working_set.boost_memories(&decision.boost_targets);
            result.boosted = boosted;
        }
        
        // Step 4: 如果没有任何操作，直接接受
        if decision.boost_targets.is_empty() 
            && decision.merge_targets.is_empty() 
            && decision.conflict_targets.is_empty() {
            let memory = self.create_memory_with_parent_ids(
                &candidate.content,
                &candidate.memory_type,
                candidate.importance,
                vec![],  // 无父记忆
            ).await?;
            result.accepted = Some(memory);
        }
        
        // 关键修正：最后统一写回 storage
        let commit_result = working_set.commit_to_storage(&self.storage).await?;
        log::info!("[DedupService] Working Set 提交完成: {:?}", commit_result);
        
        log::info!("[DedupService] Pipeline 执行完成");
        Ok(result)
    }

    // ❗关键修正：将 embedding 计算移出循环，预计算复用
    async fn recalculate_merge_targets(
        &self,
        working_set: &WorkingSet,
        candidate: &CandidateMemory,
        original_merge_targets: &[MergeTarget],
    ) -> Result<Vec<MergeTarget>, Box<dyn std::error::Error>> {
        let mut new_targets = Vec::new();
        
        // 将预计算移到循环体外部，防止重复消耗计算资源
        let candidate_embedding = self.embedding.embed(&candidate.content).await?;
        
        // 检查 original_merge_targets 是否仍然需要 merge
        for target in original_merge_targets {
            if let Some(memory) = working_set.get_memory(&target.memory_id) {
                // 计算与 candidate 的相似度
                if let Some(embedding) = &memory.embedding {
                    // ❗复用预先算好的 candidate_embedding
                    let similarity = cosine_similarity(&candidate_embedding, embedding);
                    
                    // 如果相似度仍然在 merge 范围内
                    if similarity >= self.config.accept_partial_threshold 
                        && similarity < self.config.accept_exact_threshold {
                        new_targets.push(MergeTarget {
                            memory_id: target.memory_id.clone(),
                            similarity,
                            memory_type: target.memory_type.clone(),
                        });
                    }
                }
            }
        }
        
        log::info!("[DedupService] 重新计算 merge_targets: {} -> {}", 
            original_merge_targets.len(), new_targets.len());
        
        Ok(new_targets)
    }

    async fn multi_source_merge_in_working_set(
        &self,
        working_set: &mut WorkingSet,
        candidate: &CandidateMemory,
        merge_targets: &[MergeTarget],
    ) -> Result<MergeResult, Box<dyn std::error::Error>> {
        // 关键修正：预先计算 candidate embedding，避免重复计算
        let candidate_embedding = self.embedding.embed(&candidate.content).await?;
        
        let existing_memories: Vec<MemoryItem> = merge_targets.iter()
            .filter_map(|t| working_set.get_memory(&t.memory_id).cloned())
            .collect();
        
        let request = MultiSourceMergeRequest {
            existing_memories,
            candidate: candidate.clone(),
        };
        
        let result = self.merge_service.multi_source_merge(request).await?;
        
        // 关键修正：merge 后反向去重检查
        let merged_embedding = self.embedding.embed(&result.merged_content).await?;
        let mut max_similarity = 0.0;
        let mut most_similar_id: Option<String> = None;
        
        // 收集 merge_targets 的 ID，用于过滤
        let merge_target_ids: std::collections::HashSet<String> = merge_targets.iter()
            .map(|t| t.memory_id.clone())
            .collect();
        
        // 关键修正：检查与 working set 中其他记忆的相似度
        // 必须排除 merge_targets 自己，避免"和自己比较"
        for (id, wm) in working_set.memories.iter() {
            if wm.is_deleted {
                continue;
            }
            
            // ❗关键：排除 merge_targets 自己
            if merge_target_ids.contains(id) {
                continue;
            }
            
            if let Some(existing_embedding) = &wm.memory.embedding {
                let similarity = cosine_similarity(&merged_embedding, existing_embedding);
                if similarity > max_similarity {
                    max_similarity = similarity;
                    most_similar_id = Some(id.clone());
                }
            }
        }
        
        // 如果仍然存在高相似度 memory（> accept_exact_threshold）
        // ❗关键修正：不删除旧记忆，不创建新记忆，只做 boost
        if max_similarity > self.config.accept_exact_threshold {
            log::info!("[DedupService] Merge 后发现高相似度记忆 {:.2}，执行 boost 而非创建新记忆", max_similarity);
            
            // ❗关键修正：不要删除 merge_targets
            // 原始记忆是稳定的，不应该被"误杀"
            
            // ❗关键修正：也不要创建新 memory
            
            // 只做一件事：boost 最相似的那个 memory
            if let Some(similar_id) = most_similar_id {
                let boost_target = BoostTarget {
                    memory_id: similar_id.clone(),
                    similarity: max_similarity,
                    boost_amount: self.config.boost_amount,
                };
                working_set.boost_memories(&[boost_target]);
            }
            
            // ❗关键修正：merged: false 时，merged_content 是"污染数据"
            // 未进入 storage 的内容 = 不存在
            return Ok(MergeResult {
                merged_content: String::new(),  // ❗关键：不返回无效的中间产物
                merged_importance: 0.0,         // ❗关键：无效数据
                merge_reason: format!("已有记忆足够好（相似度 {:.2}），不创建新记忆", max_similarity),
                is_fallback: false,
                parent_ids: vec![],  // 没有创建新记忆，parent_ids 为空
                merged: false,  // ❗关键：表示没有创建新记忆
            });
        }
        
        // 标记旧记忆为删除（只有在真正创建新记忆时才删除）
        for target in merge_targets {
            working_set.mark_deleted(&target.memory_id);
        }
        
        // 关键修正：parent_ids 必须包含 candidate.id，并且在这里进行统一组装，避免上游和下游重复处理
        let mut parent_ids: Vec<String> = merge_targets.iter()
            .map(|t| t.memory_id.clone())
            .collect();
        parent_ids.push(candidate.id.clone());  // ⚠️ 必须加 candidate.id
        
        let new_memory = self.create_memory_with_parent_ids(
            &result.merged_content,
            &candidate.memory_type,
            result.merged_importance,
            parent_ids.clone(),  // ❗关键：clone 一份用于返回
        ).await?;
        
        working_set.add_memory(new_memory);
        
        // ❗关键修正：返回值必须 = 实际写入的数据
        Ok(MergeResult {
            merged_content: result.merged_content,
            merged_importance: result.merged_importance,
            merge_reason: result.merge_reason,
            is_fallback: result.is_fallback,
            parent_ids,  // ❗关键：必须用同一份（包含 candidate.id）
            merged: true,  // ❗关键：表示创建了新记忆
        })
    }

    // 关键修正：创建记忆时设置 parent_ids
    async fn create_memory_with_parent_ids(
        &self,
        content: &str,
        memory_type: &MemoryType,
        importance: f32,
        parent_ids: Vec<String>,
    ) -> Result<MemoryItem, Box<dyn std::error::Error>> {
        let emb = self.embedding.embed(content).await?;
        
        let memory = MemoryItem {
            id: uuid::Uuid::new_v4().to_string(),
            content: content.to_string(),
            memory_type: memory_type.clone(),
            importance,
            score: importance,

            parent_ids,  // 关键新增：父记忆 ID

            updated_at: chrono::Utc::now().timestamp(),
            last_accessed_at: chrono::Utc::now().timestamp(),

            decay: 0.01,
        };
        
        log::info!("[DedupService] 创建新记忆: version=1, parent_ids={:?}", memory.parent_ids);
        Ok(memory)
    }
```

```rust
    pub async fn decay_with_recency(&self) -> Result<DecayResult, Box<dyn std::error::Error>> {
        log::info!("[MemoryEvolution] 开始衰减（含时间维度）");
        
        let conn = self.storage.get_connection();
        let conn = conn.lock().await;
        let now = chrono::Utc::now().timestamp();
        let recency_config = RecencyConfig::default();
        
        let mut stmt = conn.prepare(
            "SELECT id, importance, score, decay, last_accessed_at, access_count, created_at 
             FROM memory_items WHERE is_active = 1"
        )?;
        
        let items: Vec<(String, f32, f32, f32, i64, i32, i64)> = stmt.query_map([], |row| {
            Ok((row.get(0)?, row.get(1)?, row.get(2)?, row.get(3)?, row.get(4)?, row.get(5)?, row.get(6)?))
        })?.filter_map(|r| r.ok()).collect();
        
        let processed = items.len();
        let mut updated = 0;
        
        for (id, importance, _old_score, _decay, last_accessed, access_count, _created_at) in items {
            let recency_weight = calculate_recency_weight(last_accessed, &recency_config);
            let access_factor = 1.0 + (access_count as f32 * 0.05);
            
            let new_score = importance * recency_weight * access_factor;
            let new_importance = importance * 0.995;
            
            let rows = conn.execute(
                "UPDATE memory_items SET score = ?1, importance = ?2, updated_at = ?4 WHERE id = ?3",
                params![new_score, new_importance, id, now],
            )?;
            updated += rows;
        }
        
        log::info!("[MemoryEvolution] 衰减完成: 处理 {} 条, 更新 {} 条", processed, updated);
        
        Ok(DecayResult { processed, updated })
    }

                self.deactivate_memory(&memory.id).await?;
                deactivated_ids.push(memory.id.clone());
                deactivated_count += 1;
                log::info!("[MemoryEvolution] 逻辑删除低价值记忆: {} (importance={:.2}, days_inactive={})", 
                    memory.id, memory.importance, 
                    (chrono::Utc::now().timestamp() - memory.last_accessed_at) / (24 * 3600));
            }
        }
        
        log::info!("[MemoryEvolution] 逻辑删除完成: {} 条记忆", deactivated_count);
        
        Ok(DeactivationResult {
            deactivated_count,
            deactivated_ids,
        })
    }

        Ok(EvolutionResult {

            prune: prune_result,

    }
```

```typescript
  merged: boolean;  // ❗关键新增：表示是否创建了新记忆
}

export interface ConflictResolveResult {
  resolvedContent: string;
  resolvedImportance: number;
  resolveReason: string;
  parentId: string;  // 新增：父记忆 ID
}

export interface PipelineResult {
  conflictsResolved: ConflictResolveResult[];
  merged?: MergeResult;
  boosted: MemoryItem[];
  accepted?: MemoryItem;
}

export interface EvolutionResult {
  decay: DecayResult;
  deactivation: DeactivationResult;
  prune: PruneResult;
}

export interface DeactivationResult {
  deactivatedCount: number;
  deactivatedIds: string[];
}
```

## 流程图

### Accept 阶段（Working Set + Pipeline）

```
用户点击接受
    │
    ▼
┌─────────────────────────────┐
│ Retrieval(top_k=10,         │
│   min_similarity=0.75)      │
└─────────────┬───────────────┘
              │
              ▼
        分类所有相似记忆
              │
              ├── similarity >= 0.85 → boost_targets
              │
              ├── similarity >= 0.75 → 冲突检测（最多 3 条）
              │       │
              │       ├── 有冲突 → conflict_targets
              │       └── 无冲突 → merge_targets
              │
              └── similarity < 0.75 → 忽略
              │
              ▼
        返回 DedupDecision
              │
              ▼
┌─────────────────────────────┐
│ 创建 Working Set            │
│ load_from_storage()         │
└─────────────┬───────────────┘
              │
              ▼
        Pipeline 执行（内存态）
              │
              ├── 1. ResolveConflicts
              │       └── 修改 Working Set
              │
              ├── 2. 重新计算 merge_targets
              │       └── 基于 Working Set（不是 storage）
              │
              ├── 3. MultiSourceMerge
              │       └── 修改 Working Set
              │
              ├── 4. BoostMemories（递减收益）
              │       └── 修改 Working Set
              │
              └── 5. 如果都为空 → Accept
              │
              ▼
┌─────────────────────────────┐
│ commit_to_storage()         │
│ （最后统一写回）             │
└─────────────────────────────┘
```

### 演化周期

```
run_full_evolution()
    │
    ├── 1. decay_with_recency()
    │       └── score = importance * recency_weight * access_factor
    │
    ├── 2. deactivate_low_value_memories()
    │       └── if importance < 0.2 && days_inactive > 30 → is_active = false
    │
    └── 3. prune()
            └── if score < 0.3 → is_active = false
```
